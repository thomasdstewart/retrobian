# Installation notes

1. At boot prompt press Enter
1. Select Color
1. Select Next
1. Select Exit
1. Select "Next Configure the Keyboard"
1. Select "uk"
1. Select "Next Partition A Hard Disk"
1. Select "/dev/hda" and OK
1. Create One big partition
1. Select "Alternate Do Without a Swap Parition"
1. Select Yes
1. Select "Next Initialize A Linux Disk Partition"
1. Select "/dev/hda1"
1. Select No for Bad Blocks scan
1. Select Yes to Confirm initilize
1. Select "Yes" to mount as root filesystem
1. Select "Next Install Operating System Kernel and Modules"
1. Select "Yes" to confirm install
1. Select "hardisk" and OK
1. Select "/dev/hdb1" and OK
1. Select "default" and OK
1. Select "Next Configure Device Driver Modules"
1. Select "net"
1. Select "ne"
1. Select "Install"
1. Type "irq=9 io=0x300" and OK
1. Expect Installation succeeded, Enter to continue
1. Select Exit
1. Select Exit
1. Select "Next  Configure the Network"
1. Press Enter to set hostname to debian
1. Select yes to use a network
1. Type "lan" and Enter to set domain
1. Select Yes to confirm fqdn
1. Enter IP: 192.168.122.10
1. Enter netmask: 255.255.255.0
1. Enter network: 192.168.122.0
1. Enter broadcast: 192.168.122.255
1. Enter Yes for Gateway
1. Enter 192.168.122.1 for gateway
1. Select "2 Another system will be the DNS server"
1. Enter Name Server: 192.168.122.1 
1. Select Yes to confirm
1. Select Yes to use Ethernet
1. Select "Next Install the Base system"
1. Select "hardisk" and OK
1. Select "/dev/hdb1" and OK
1. Select "default" and OK
1. Select "Next Configure the Base System"
1. Type "Europe" Enter "London" Enter
1. type y to set system clock to GMT
1. Select "Next Make Linux Bootable Directly From Hard Disk"
1. Select Yes to install MBR to /dev/hda
1. Select Yes to boot system on /dev/hda1
1. Select "Next Make a boot Floppy" and OK
1. Select "Next Reboot The System"
1. Select "Yes" to confirm reboot
1. Set root password
1. Create user account
1. dselect, select quit
1. exit and login as root
1. run: mount /dev/hdb1 /mnt
1. run: cp /mnt/netscape* /tmp
1. run: cp /mnt/XF86Config /root
1. run: umount /mnt
1. run: dselect
1. Select Access, harddisk, enter /dev/hdb1, enter ext2, enter /, enter none for local, return
1. Select Update, Enter
1. Select Select, space, enter
1. Select Install
1. Select Config
1. Select Remove
1. Sekect Select, choose: sudo, autoconf, vim, gnuchess, xfig, xpaint, gnuplot, screen, bind, cern-httpd, lynx, tcpdump, wu-ftpd, a2gs, ghostview, hdparm, minicom, python, samba, xntp3, xsysinfo, ddd, gimp-dmotif, netscape, xbase, xserver-vga16, fvwm95 and enter
1. Select Install
1. Select Config
1. Select Remote
1. Select Quit
1. run: cp /root/XF86Config /etc/X11
1. run: lilo
1. run: shutdown -h now
