# Installation notes

1. At boot prompt enter: "linux root=/dev/fd1"
1. At "Insert Root Disk" prompt press Enter
1. Select OK
1. Select Continue
1. Select Expert
1. Select "1 Partition a Hard Disk"
1. Create One big partition
1. Select "3 Prepare A Linux Partition"
1. Enter: "/dev/hda1"
1. Select "4 Mount/Unmount Partitions"
1. Enter: m, hda1, / and c
1. Select: "5 Install Debian GNU/Linux"
1. Select yes to use /dev/hda1 as root
1. Select: /dev/fd0
1. run on host: cp repo/disks/1440_base_floppy-1 fda.img
1. Press Enter
1. run on host: cp repo/disks/1440_base_floppy-2 fda.img
1. Press Enter
1. run on host: cp repo/disks/1440_base_floppy-3 fda.img
1. Press Enter
1. Select: "6 Configure Debian GNU/Linux"
1. Select yes to use /dev/hda1 as root
1. Select no to choose different keymap
1. Type: uk.map
1. At Block Modules Setup Select OK
1. At File System Modules Select OK
1. At Network Modules Select OK
1. At Miscellaneis Modules Select OK
1. Press Enter to set hostname to debian
1. Press Enter to set empty domain
1. Press y to confirm
1. Type Europe Enter and London Enter to set timezone
1. type y to set system clock to GMT
1. Select: "7 Make A Boot Diskette"
1. Press Enter
1. Select: "9 Reboot The System"
1. Login as root
1. Set password
1. Create user account
1. dselect, select quit
1. login as root
1. run: mount /dev/hdb1 /mnt
1. run: cat /mnt/network >> /etc/init.d/network
1. run: echo "nameserver 8.8.8.8" > /etc/resolv.conf
1. run: sed 's/^#telnet/telnet/' /etc/inetd.conf > /etc/inetd.conf.new
1. run: mv /etc/inetd.conf.new /etc/inetd.conf
1. run: dselect
1. Select Access, harddrive, yes, type /mnt/binary, pres enter to confirm /mnt/binary/Packages
1. Select Update
1. Select Select, space, enter, space, enter
1. Select Install, when prompted install a lilo boot block, choose y to replace config files
1. Select Config
1. Select Remove
1. Select Select, choose: sudo, autoconf, tcl, tk, vim, gnuchess, xboard, xfig, gnuplot, screen, bind, cern-httpd, lynx, tcpdump, wu-ftpd, a2gs, ghostview, All Optional section x11, hdparm, minicom, python, samba, xntp, and enter
1. lelect Install, when promped for xfree86 setup, choose n
1. Select Config
1. Select Remote
1. Select Quit
1. run: cp /mnt/XF86Config /etc/X11
1. run: ln -s /usr/X11R6/bin/XF86_VGA16 /etc/X11/X
1. run: startx (test X works)
1. run: sed 's/^run_xdm=0/run_xdm=1/' /etc/init.d/xdm > /tmp/xdm
1. run: cat /tmp/xdm > /etc/init.d/xdm
1. run: rm /tmp/xdm
1. run: lilo
1. run: shutdown -h now
